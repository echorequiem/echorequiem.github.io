简介

将 MusicXML 乐谱转换为滚动的乐谱视频，正在发声的音符会以你选择的颜色发光。可添加背景图片或视频、音乐音轨以及片头 / 片尾画面；结果逐帧导出为 MP4 或 WebM，最高 4K。无需联网：一切都留在你的电脑上。

功能

  • 打开 MusicXML（.musicxml、.xml、.mxl），并从文件读取速度及速度变化
  • 正在发声的音符按其时值发光；颤音闪烁，连线如流水般流动
  • MP4（H.264 + AAC）或 WebM（VP9 + Opus）· 720p 至 4K · 24–120 fps · 16:9、9:16、1:1、4:3、4:5
  • 背景图片或视频、薄雾与火星效果、可精确到毫秒偏移的音乐音轨
  • 片头与片尾画面（视频和 / 或三种文字模板）；乐谱逐一就位开始，逐一消失结束
  • 渲染前预览最终视频、保存项目、高清乐谱长条图片、10 种界面语言
